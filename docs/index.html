Seven tabs, one gesture.

Everything lives behind the camera. Each tab is one keyboard shortcut away: Control-Command and a number from 1 to 7.

Nook

A row of widgets you choose: now playing, calendar, focus timer, weather, to-dos, notes, volume, quick apps, a mirror and more. Reorder them in Settings.

Music

Artwork, a scrubber, playback controls and synced lyrics for Spotify and Apple Music. While a song plays, the closed notch shows the cover and a small equalizer.

Calendar

A day strip and your agenda, with a Join button for video calls. A reminder appears in the notch before a meeting starts.

Tray

Drag a file to the top of the screen and drop it in the notch. It stays there until you drag it out, AirDrop it or remove it.

Clipboard

Everything you copy: text, links, colors, images and files. Search it, filter it, and pin favorites. Passwords and the apps you exclude are never saved.

Prompter

A teleprompter under the camera. Paste a script, press play, and read while you keep eye contact.

Agents

See what Claude Code is doing in each project: the current step, and an alert in the notch when it needs you.

Live activities

When the notch is closed it still shows what matters: the song, a running timer, battery charging, an agent at work, or a volume change.

Install in a minute.

Notchly is not notarized by Apple yet, so macOS asks once before the first launch.

  1. DownloadGet Notchly.zip from the latest release and unzip it.
  2. Move itDrag Notchly.app to your Applications folder.
  3. Allow it onceOpen the app. When macOS blocks it, go to System Settings, Privacy & Security, and click Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/Notchly.app.

Notchly lives in the menu bar. To update, choose Check for Updates in its menu and replace the app. Each release lists a SHA-256 checksum so you can verify the download.

Open source, end to end.

Notchly is plain Swift with SwiftUI and AppKit. It has no accounts, no analytics and no third-party packages.

  • MIT license: use it, change it, ship your own version.
  • Your data stays on your Mac, in Application Support.
  • Network use is limited to weather (Open-Meteo), lyrics (LRCLIB, can be turned off), Spotify album art, and update checks you start yourself.
# build from source
$ git clone https://github.com/SuzalShrestha/notchly
$ cd notchly
$ ./make-app.sh --run
# self-tests and snapshots
$ ./verify.sh

Questions.

Does it work on a Mac without a notch?

Yes. On a MacBook Air without a notch, or on an external display, Notchly shows a thin handle at the top center of the screen. Point at it and the notch opens the same way. You can turn this off, or pick which displays to use, in Settings.

Why does macOS warn me when I open it?

Release builds are signed ad hoc and not notarized by Apple, so Gatekeeper asks once. Allow it in System Settings › Privacy & Security, or build it yourself from source. Every release has a SHA-256 checksum you can check with shasum -a 256 -c Notchly.zip.sha256.

Which music apps does it support?

Spotify and Apple Music. Notchly reads the current track and controls playback through Automation, so macOS asks once for permission. Browsers and other players are not supported yet.

How do I connect Claude Code?

Open Settings › Agents & AI Usage and click Install hooks. Notchly adds a small script to your Claude Code hooks and keeps the ones you already have, with a backup of the old file. Start a new Claude Code session and it shows up in the Agents tab. Remove hooks takes them out again.

Is my clipboard history private?

It never leaves your Mac. Items that password managers mark as concealed are skipped, you can exclude apps, set how long history is kept, or clear it on quit. Favorites stay until you remove them.

How do I uninstall it?

If you connected Claude Code, click Remove hooks first. Then quit Notchly from the menu bar and delete the app. Your data is in ~/Library/Application Support/Notchly; delete that folder to remove it too.
